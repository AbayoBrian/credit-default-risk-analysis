# Dataset

The analysis downloads the UCI **Default of Credit Card Clients** dataset on first run using `ucimlrepo`.

Source: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients  
DOI: https://doi.org/10.24432/C55S3H

Do not commit private borrower data. The dataset is publicly available for research/education. Review the repository's current dataset terms before redistribution.
